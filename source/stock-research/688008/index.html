moat

为什么报告写成“技术护城河最深”

报告没有抽象地说“研发能力强”，而是把壁垒拆成四条可验证、可传导到利润与估值的话：标准制定、强制性需求、代际自动涨价，以及 CXL 这条从 0 到 1 的新曲线。

01

标准制定者

深度参与 DDR5、DDR6 国际标准制定，竞争对手必须追赶澜起，而非澜起追赶别人。

02

强制性需求

三星、海力士、美光生产 DDR5 必须使用澜起的 RCD/CKD 芯片，切换成本极高。

03

代际自动涨价

从 DDR5 第一子代到第三子代，RCD 单价每代提升 15%–25%，形成内生涨价机制。

04

CXL 新曲线

PCIe Retimer / MRCD / MDB / CXL MXC 新品对应 AI 数据中心内存扩展核心需求，从 0 到 1。

“竞争对手必须追赶澜起，而非澜起追赶别人。”

利润弹性已经显形

2025H1 净利同比 +95%，明显快于营收同比 +58%。这不是单季惊喜，而是产品结构和经营杠杆开始同步兑现。

毛利率不是静态数字

从约 61% 到 64%，说明公司没有在放量中牺牲质量。对于站在标准与接口位置上的芯片公司，毛利率抬升很能说明壁垒强度。

新产品起量很关键

新产品收入 2.94 亿元，是“第二增长曲线开始落地”的早期证据，也为 CXL 估值重构埋下伏笔。

估值争议，本质上是方法争议

报告写得很明确：当前股价 150.31 元，2025 / 2026 / 2027 年预测 PE 约 187 倍 / 74 倍 / 44 倍。但同时又强调：PE 不是正确工具，应以标准制定者的终局市场价值 + 代际涨价的永续性来定价。

“DDR5 渗透率见顶 ≠ 澜起业绩见顶。”

报告反驳空头逻辑的核心句。

空头逻辑

DDR5 渗透率见顶 → 澜起 2026 年净利负增长。这是一种把渗透率放缓直接外推为公司盈利能力见顶的判断。

报告的反驳

子代迭代涨价与 CXL 新产品是两条独立增长引擎，不依赖渗透率加速。即使 DDR5 渗透率进入平台期，单价仍因代际升级持续提升。

new curve

CXL 为什么是下一个估值重构引擎

CXL 是 AI 时代数据中心内存扩展的核心协议，解决 GPU 算力爆发后的内存带宽瓶颈。澜起 CXL MXC 芯片已送样，一旦验证完成进入量产，收入体量将远超当前 DDR5 RCD 业务。

A

AI 训练负载上升

GPU 算力提升后，数据中心越来越容易遇到内存带宽与容量瓶颈。

B

CXL 的角色

CXL 被报告定义为 AI 数据中心内存扩展的核心协议。

C

MXC 已送样

澜起 CXL MXC 芯片已送样，故事进入客户验证阶段。

D

量产打开曲线

验证完成并进入量产后，收入体量有望远超当前 DDR5 RCD 业务。

E

单颗价值量更高

CXL 芯片单颗价值量显著高于 DDR5 RCD，产品结构升级将推动毛利率进一步提升至 70%+。

F

市场仍未充分定价

报告判断这是一条从 0 到 1 的新曲线，不是 DDR5 的线性外推。

“这不是 DDR5 的线性外推，而是一条从 0 到 1 的新曲线。”

这句话定义了报告对 CXL 的估值语气。

真正能重构估值的，不是“又一个新产品”，而是新产品同时具备更高价值量、更高毛利弹性，以及新的产业必要性。

研究框架

输入是产业位置与标准地位；过程是把壁垒翻译成财务，再把财务翻译成估值；工具是产品路线图、验证进度、季报与事件日历；产出是对价格与风险更有边界的判断；反馈闭环来自每一次验证是否兑现。

为什么比情绪更重要

情绪会反复，但节点可跟踪。真正有用的复盘，不是“当时觉得会涨”，而是“当时盯住了哪些事实，后来这些事实有没有发生”。

核心总结

报告真正想说明的，不是公司“还不错”，而是它可能同时踩中标准、接口与下一代内存扩展三个关键位置。

个人观察

最值得复盘的不是目标价，而是研究者如何把“标准权”翻译成“估值权”。这套方法论比单次判断更有价值。

给研究者的提醒

不要把单一结论当作替代独立判断的答案。所有判断都应回到数据、验证进度、风险边界与时间节点。
